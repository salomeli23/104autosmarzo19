<analysis>**original_problem_statement:**
Diseña y desarrolla una aplicación web responsive (compatible con dispositivos móviles) para la gestión de agendamiento y operación de servicios técnicos automotrices. La aplicación debe permitir administrar servicios como Polarizado, Nanocerámica, etc. Debe contar con roles de usuario (Administrador, Asesor comercial, Técnico) y funcionalidades para autenticación, agendamiento, ingreso de vehículo, revisión 360°, cotización, orden de servicio, asignación de trabajo y seguimiento de estado.

**PRODUCT REQUIREMENTS (LATEST UPDATE):**
El flujo de la aplicación ha sido redefinido por el usuario de la siguiente manera:
1.  **Agendamiento:** Se crea una nueva cita con un valor negociado. El estado es Agendado. Se genera un código QR y un código de cita.
2.  **Ingreso:** Se hace check-in del vehículo usando el QR/código. El asesor puede ofrecer servicios adicionales (upsell). El cliente aprueba la orden actualizada con firma digital, número de cédula y una foto de la orden. El estado cambia a Ingresado.
3.  **Revisión 360:** Se realiza una inspección del vehículo con fotos y video.
4.  **Asignación:** Un rol Coordinador asigna el trabajo a un técnico y establece un tiempo estimado (timer) para el servicio.
5.  **En Proceso:** El técnico trabaja en el vehículo y puede reportar observaciones.
6.  **Facturación y Entrega:** Un rol de Facturación gestiona el pago. Los estados finales son Terminado y falta de pago o Terminado y pagado y entregado. Se toma una foto final en la entrega.
También se requieren alertas, la opción de desistimiento de servicio para el coordinador y la gestión de bonos/promociones.

**User's preferred language**: Spanish

**what currently exists?**
Se ha desarrollado una base de aplicación full-stack con FastAPI (backend) y React (frontend). La UI utiliza Tailwind CSS y componentes de Shadcn, con un tema oscuro basado en el logo del cliente. Se implementó la autenticación de usuarios (JWT), el registro automático de vehículos al crear una cita (evitando duplicados), un sistema básico de estados de vehículos y la capacidad de asignar técnicos. La página de inspección incluye un componente para captura de cámara y se ha eliminado la opción de registro del login.
